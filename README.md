## 第 1 步：拿 API Key（5 分钟）

1. 浏览器打开 **https://platform.deepseek.com/api_keys**
   （已帮你用便携 Chrome 打开；**别用系统自带的 Edge**，它禁用了 JS）
2. 点右上角 **登录/注册** → **手机号验证码注册**（不用实名，30 秒搞定）
3. 登录后进入 **API Keys** 页面
4. 点 **创建 API Key**
   - 名称随便填，比如 `jerry-study`
   - 有效期建议选 **较长的**（比如半年，省得中途过期又要重新弄）
5. **复制那串以 `sk-` 开头的字符** ⚠️ **只显示一次，关掉页面就看不到了**
6. 存到记事本里先

> 💡 为什么选 DeepSeek 而不是文档里写的通义千问？
> 通义需要**阿里云实名认证**（上传证件 + 人脸），门槛高；DeepSeek 手机号秒注册，
> 且输入价格极低（约 ¥0.18/百万 token），练手阶段几乎不花钱。
> **两家接口格式完全一样**，学完 DeepSeek 想换通义，改两个字符串就行。

## 第 2 步：把 Key 放进环境变量

### 方案 A：临时生效（只对当前这个终端窗口有效，推荐先用这个）

在 **PowerShell** 里执行（把引号里的内容换成你的真 Key）：

```powershell
$env:DEEPSEEK_API_KEY = "sk-你的key"
```

### 方案 B：永久生效（之后所有终端都能用）

```powershell
setx DEEPSEEK_API_KEY "sk-你的key"
```

> ⚠️ 用完 `setx` **必须重开一个终端窗口**才生效。
> 想永久生效还要把 `C:\Users\lenovo\AppData\Roaming\Microsoft\Windows\PowerShell\profile.ps1`
> 里的执行策略放开（如果你之前遇到过 npm.ps1 无法加载的报错，就是它）。

## 第 4 步：常见报错对照表

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `❌ 没有读到 API Key！` | 环境变量没设 | 回到第 2 步；注意 `setx` 后要重开终端 |
| `401 未经授权` | Key 抄错了 / 带空格 / 已过期 | 回平台重新复制，注意不要带首尾空格 |
| `402 余额不足` | 账户没余额 | 去 platform.deepseek.com 充值（1 元起） |
| `429` | 请求太频繁 | 等几秒重试 |
| `400` | 请求体有问题 | 检查 `model` 名是否写成 `deepseek-chat` |
| `fetch failed` | 网络问题 | 关掉 VPN/加速器；或执行 `$env:HTTP_PROXY=""` |

## 第 5 步：改点东西试试（这才是重点）

跑通之后，**改三个地方，每改一次跑一次**，看输出有什么变化：

1. **换问题**：`content` 改成 `"用一句话解释什么是数据库索引"`
2. **换角色**：`system` 改成 `"你是一个只会说 Python 笑话的 comedian"`，看它怎么变
3. **换温度**：`temperature` 从 `0.7` 改成 `0`，再跑一次 —— 同样的问题，答案会**完全一样**
   （这就是"确定性"，做批量数据处理时必须用 0）
